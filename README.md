# Task_Ticket_Manager
This will be a project where we will be making a Task Ticket Manager 

# Instructions 
These instructions will describing how to properly start your virtual enviornment inside of the project. 
The following commands are what you are going  to use: 

Using VSCode open a terminal. You can do this by doing Ctrl+Shift+` or click terminal in the top left and clicking new terminal 
Make sure your in the correct folder within the terminal. (Usually when opening a terminal in vscode it automatically puts you in the folder directory.)

Then run the first step. 

1. python -m venv .venv                    // Builds the virtual enviornment

After Step 1 run step two depending on which OS your on. 
2. source .venv/bin/activate               // Activates the virtual enviornment (Mac/Linux)
    .\.venv\Scripts\Activate.ps1           // Activates the virtual enviornment (Windows Powershell)

After running step 2, the terminal should have a "(.venv)" prefix and then the folder directory. 
If you have that then run the third step. 

3. pip install -r requirements.txt         // Installs all packages currently needed
